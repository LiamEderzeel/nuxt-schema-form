::callout{icon="i-heroicons-light-bulb"}
Nuxt Schema Form is built on **Nuxt UI v4**. See [Nuxt UI](https://ui.nuxt.com/) for more information.
::

## Quick Start

1. Install `@ederzeel/nuxt-schema-form` in your project:

```bash
npx nuxi@latest module add @ederzeel/nuxt-schema-form
```

2. Make sure `@ederzeel/nuxt-schema-form` is in your `nuxt.config` modules:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@ederzeel/nuxt-schema-form']
})
```

3. Import the module's styles in your main CSS file, after Nuxt UI, so Tailwind picks up the classes its components use:

```css [assets/css/main.css]
@import 'tailwindcss';
@import '@nuxt/ui';
@import '@ederzeel/nuxt-schema-form';
```

## Configuration

You can set the module options with the `schemaForm` key in `nuxt.config`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@ederzeel/nuxt-schema-form'],
  schemaForm: {
    // Module Options
  }
})
```
