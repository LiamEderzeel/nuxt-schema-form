::

## Quick Start

1. Install `@ederzeel/nuxt-form` as a dev dependency to your project:

```bash
npx nuxi@latest module add @ederzeel/nuxt-form
```

2. Add `@ederzeel/nuxt-from` to your `nuxt.config` modules:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@ederzeel/nuxt-schema-form']
})
```

## Configuration

You can set the module options by using the `form` property in `nuxt.config` root.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@ederzeel/nuxt-schema-form'],
  schemaForm: {
    // Module Options
  }
})
```
