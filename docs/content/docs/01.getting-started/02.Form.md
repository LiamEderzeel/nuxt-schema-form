## Generate a form from a schema

::component-code
---
ignore: 
  - schema
  - schema.type
  - schema.required
  - test.type
  - test.default
  - model-value
  - model-value.test
external:
  - schema
  - model-value
props: 
  model-value:
    test: "test"
  schema:
    type: "object"
    required: 
      - test
    properties:
      test: 
        type: "string"
        default: "test"
---
::
