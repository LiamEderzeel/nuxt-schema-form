## Generate a form with Schem-form

::component-code
---
ignore: 
  - schema
  - schema.type
  - schema.required
  - test.type
  - test.default
  - model-value
  - model-value.test
external:
  - schema
  - model-value
props: 
  model-value:
    test: "test"
  schema:
    type: "object"
    required: 
      - test
    properties:
      test: 
        type: "string"
        default: "test"
---
::

## Layout

By default every property gets its own row. To put fields side by side, add a `layout` to the object that holds them. Each entry is a row: a list of property names renders on one line, a single name renders full width.

```json
{
  "type": "object",
  "layout": [
    ["firstname", "lastname"],
    [{ "key": "street", "width": 3 }, "number"]
  ],
  "properties": {
    "firstname": { "type": "string" },
    "lastname": { "type": "string" },
    "street": { "type": "string" },
    "number": { "type": "number" },
    "email": { "type": "string" }
  }
}
```

- Use `{ "key": "street", "width": 3 }` to give a field a bigger share of the row. Widths are relative and default to `1`, so the row above is split ¾ and ¼.
- Properties not mentioned in `layout` are rendered after it, full width, in their normal order (`email` above).
- On small screens, rows stack vertically.
- `layout` only changes how the form looks. The data keeps the same shape as `properties`.
